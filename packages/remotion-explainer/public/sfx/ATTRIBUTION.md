# Sound effects attribution

All files in this folder are third-party open assets. We do not synthesize waveforms.

## Remotion / remotion.media
- whoosh, whip, page-turn, switch, mouse-click, shutter-modern, shutter-old, ding,
  vine-boom, dramatic-boomer, record-scratch, snapchat-notification
- Package: `@remotion/sfx` (MIT). Per-sound licenses on remotion.dev detail pages;
  Remotion documents these as usable without attribution.

## Kenney UI Audio (CC0 1.0)
- kenney-click-*.wav, kenney-switch-*.wav, kenney-mouseclick.wav, kenney-rollover.wav
- Original: https://kenney.nl/assets/ui-audio
- Mirror: https://github.com/Calinou/kenney-ui-audio

## Kenney Interface / Impact / Sci-Fi Sounds (CC0 1.0)
- iface-*.ogg, impact-*.ogg, scifi-*.ogg
- Original: https://kenney.nl (Interface Sounds, Impact Sounds, Sci-Fi Sounds)
- Mirror used for fetch: https://github.com/kapishdima/soundcn (assets/)

Aliases: `click.wav` → mouse-click; `lowboom.wav` → vine-boom (legacy SceneMotion names).
